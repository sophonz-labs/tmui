**tmui's parts are Go packages other tools can import.** The `tmui` program works as in v0.2.2. What is new is under `pkg/`, which st's `st ui` and stui already build on:

- **`pkg/workspace`, the workspace frame.**
  - A tmux client runs in the middle.
  - The sidebar shows the machine's sessions, windows and agents. An orchestration run is a tree: workers sit under their coordinator, also from another session, and stay in view when their lead's session is folded.
  - The right panel has seven icon tabs: Terminal, AI Usage, CI, Git, Agents, History and Docs. AI Usage lists every limit window with when it resets and the pace.
  - It has a menu bar, the mouse, and the `ctrl-]` prefix. `ctrl-] b` toggles the sidebar and `ctrl-] p` the panel.
  - The host program supplies the rest through `workspace.Host`.
- **`pkg/vterm`:** a program in a pseudo-terminal, kept by a pure Go VT emulator.
- **`pkg/termmd`:** markdown drawn for a terminal.
- **`pkg/pricing`:** tokens priced at public API rates.
- **`pkg/config`, `pkg/plugin`, `pkg/upgrade` and `pkg/clip`:** moved out of `internal/` so other tools can import them. A tool keeps its own settings under `ui` in the config file.

AI Usage reads `resetsAt` as Unix milliseconds, as `/api/usage` sends it. It used to read it as seconds, so a reset showed as decades away.
