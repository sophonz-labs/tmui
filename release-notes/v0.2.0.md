tmui takes plugins now, keeps its settings in a file, and draws its logo in the header.

**Plugins.** A plugin is one `plugin.json` that brings another CLI into tmui: a view that turns a command's output into a table (`gh pr list --json …`, `docker ps`, `kubectl get pods`), keys on its rows and on your panes, and `:` commands. Install one by name from [sophonz-labs/tui-plugins](https://github.com/sophonz-labs/tui-plugins):

```sh
tmui ext install gh-prs
```

The installer prints every command the plugin will run and asks before it writes anything. `:ext` lists what is installed, and a plugin can never take one of tmui's own keys. Six plugins to start: `gh-prs`, `gh-runs`, `docker-ps`, `kubectl-pods`, `git-status`, `lazygit`.

**Settings.** `~/.config/tmui/config.yaml`, as k9s keeps its own: the logo, the header, colour, the refresh rate, the first view, and plugins on or off. `tmui config edit` makes the file with every default in it, `:config` shows what is in effect, and tmui reads the file again when you save it. `ctrl-e` hides the header, `:logo` the logo.

**The logo** sits at the top right of the header from 116 columns and 20 rows; below that, the name.
