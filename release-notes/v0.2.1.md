**`tmui upgrade`** replaces tmui with the latest release, the way `install.sh` put it there: it reads which release is latest, downloads the archive for this machine, checks it against that release's SHA-256 and swaps the binary in one rename. It then prints the new release's notes.

```sh
tmui upgrade                    # to the latest release
tmui upgrade --check            # only say whether there is one
tmui upgrade --version v0.2.0   # this release, older ones too
```

A tmui installed by Homebrew is left to `brew upgrade`, and when tmui cannot write to its own directory it prints the install line that can.
