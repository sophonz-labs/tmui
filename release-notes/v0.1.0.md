First release.

- Sessions, windows and panes of a tmux server in one screen, refreshed every 2 seconds.
- A pane's output (its last 2000 lines) in a pager, with `/` search and `n`/`N`.
- Make, rename and kill sessions and windows; split and kill panes.
- `a` attaches and comes back: outside tmux, detach with `prefix d`; inside tmux 3.2+, the session opens in a full-size popup and `prefix d` closes it.
- `:tmux <args>` runs any tmux command on the same server.
- `-L` and `-S` pick the server, as tmux does.
